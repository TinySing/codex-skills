# AR Skill 输出参考

按任务选择结构，不要机械套模板。

## 1. 架构咨询

- 结论
- 适用场景
- 不适用场景
- 核心取舍
- 判断标准
- 示例

## 2. 技术方案

- 开发前置要求：环境、依赖、账号、密钥、样例数据、联调方式
- 目标与范围
- 现状与约束
- 总体技术决策：已选方案、原因、放弃方案
- 系统边界
- 模块职责
- 数据流 / 调用链 / 关键时序
- 核心数据模型或状态模型
- API / 事件 / 任务 / 文件 / 权限契约边界
- 关键不变量
- 一致性、事务、幂等、并发策略
- 缓存、队列、实时、文件等专项设计
- 安全、性能、可靠性、可观测性、可维护性
- 扩展性和演进策略
- 部署、发布、回滚
- 分阶段落地顺序
- 验收方式
- 实施边界与质量保障

## 4. 架构评审

- Findings first
- 每条包含：问题、影响、优先级、修改建议、验证方式
- 证据范围
- 建议补读材料
- 总结

## 5. 故障诊断

- 现象复述
- 最可能原因
- 排查顺序
- 需要补充的证据
- 修复建议
- 防复发措施

## 6. 重构规划

- 当前问题
- 不建议继续堆补丁的理由
- 目标边界
- 分阶段改造路径
- 兼容策略
- 数据迁移与回滚策略
- 质量保障方式
- 验收方式
